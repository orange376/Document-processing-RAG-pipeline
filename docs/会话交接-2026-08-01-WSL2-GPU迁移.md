## 三、当前任务：WSL2 GPU 迁移（进行中）

### 背景
- 用户机器有 **NVIDIA RTX 4060 (8GB)**，但 Windows 端 torch 是 CPU 版（`torch.cuda.is_available()=False`）
- 用户选择「切换 GPU」，并接受 **WSL2 路径**（Linux 下 paddle GPU + torch CUDA wheel 支持更好）
- 用户提示：**用国内镜像下载更快**（已配置）

### WSL2 环境当前状态

| 项目 | 状态 | 详情 |
|------|------|------|
| WSL2 Ubuntu | ✅ | Ubuntu 26.04 LTS，7.6GB RAM，磁盘 955G 空余 |
| GPU 透传 | ✅ | WSL 内 `nvidia-smi` 能看到 RTX 4060，驱动 CUDA 13.3 UMD |
| `uv` 0.12.1 | ✅ | `~/.local/bin/uv`（用户级，免 sudo） |
| Python 3.12.13 | ✅ | 经 uv 安装（系统 python 是 3.14，paddle 不支持，故用 3.12） |
| 项目克隆 | ✅ | `~/rag-pipeline`（git clone depth 1） |
| venv | ✅ | `~/rag-pipeline/.venv`（uv venv --python 3.12） |
| **torch CUDA** | ⏸️ **安装中** | 从 pytorch.org cu126 索引装，下载大（含 triton 188MB）在国内慢，两次超时未完成 |

### 镜像配置（已写入 `~/.bashrc`）

## 四、恢复步骤（新对话按此继续）

> 每次进 WSL 先 `wsl -d Ubuntu`；装包先 `source ~/rag-pipeline/.venv/bin/activate`。

### 步骤 1：完成 torch CUDA 安装（可能已部分下载）
```bash
wsl -d Ubuntu
cd ~/rag-pipeline && source .venv/bin/activate
# 官方 CUDA 索引（国内慢，耐心等；triton 大）
uv pip install 'torch>=2.5' 'torchvision>=0.20' --index-url https://download.pytorch.org/whl/cu126
python -c 'import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))'
# 期望输出: True NVIDIA GeForce RTX 4060
```
> 若 cu126 无匹配版本，试 cu128（torch 2.13 时代新 CUDA 索引）：
> `--index-url https://download.pytorch.org/whl/cu128`

### 步骤 2：安装项目依赖（用清华镜像，快）
```bash
cd ~/rag-pipeline && source .venv/bin/activate
# 装全依赖（会带 CPU paddle，下一步换 GPU）
uv pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
# 换 paddle GPU（Linux py312 有 GPU wheel；版本选兼容当前 CUDA 的）
uv pip install paddlepaddle-gpu --force-reinstall -i https://pypi.tuna.tsinghua.edu.cn/simple
python -c 'import paddle; print(paddle.is_compiled_with_cuda())'
# 期望输出: True
```
> 若 `paddlepaddle-gpu` 默认版本不兼容 CUDA 13.3，从 paddle 官方源装指定 CUDA 版：
> `uv pip install paddlepaddle-gpu==<版本> -f https://www.paddlepaddle.org.cn/packages/stable/cu126/`

### 步骤 3：下载模型（HF 镜像）
```bash
cd ~/rag-pipeline && source .venv/bin/activate
export HF_ENDPOINT=https://hf-mirror.com
# 创建 models 目录结构（Windows 端对应 data/models/）
mkdir -p data/models/bge-base-zh data/models/bge-reranker data/models/latex-ocr
python -c "
from sentence_transformers import SentenceTransformer
SentenceTransformer('BAAI/bge-base-zh-v1.5', cache_folder='data/models/bge-base-zh', device='cpu')
SentenceTransformer('BAAI/bge-reranker-base', cache_folder='data/models/bge-reranker', device='cpu')
"
# pix2tex 权重：首次调用 LatexOCREngine.recognize 自动下载（~200MB）
# PP-DocLayoutV3：首次版面分析自动下载到 ~/.paddlex/official_models/
```

### 步骤 4：配置 GPU 推理 + 启动
```bash
cd ~/rag-pipeline && source .venv/bin/activate
# settings.py 的 device="cuda" 已默认；确认 onnxruntime 用 CUDA provider
# 首次 embed 前预导出 ONNX（可选，避免首次请求慢）：
#   python -c "from src.index.embedding import EmbeddingEngine; e=EmbeddingEngine(); print(len(e.embed('测试')))"
nohup python run.py > server.log 2>&1 &
curl http://localhost:8001/api/v1/health
```
> WSL2 端口 8001 自动映射到 Windows localhost，浏览器访问 `http://localhost:8001`。

### 步骤 5：验证 GPU 端到端
- 上传高数模拟题 docx → 检查公式切片（pix2tex 结构正确）
- 上传课程论文 PDF → 记录版面分析耗时（CPU 2m47s → GPU 期望 ~15s）与 embed 耗时
- 问答回归：查询公式/图表内容
